// Descrição
Verificar que o sistema permite o acesso de um usuário registrado com e-mail e senha válidos, redirecionando-o corretamente ao dashboard após a autenticação bem-sucedida.
// Passos de execução
  1. Acessar a página de login em /login
  2. Inserir o e-mail válido no campo "E-mail": teste@a2gtest.com
  3. Inserir a senha correta no campo "Senha"
  4. Clicar no botão "Entrar"
  5. Aguardar o processamento da requisição de autenticação
  6. Verificar o redirecionamento para o dashboard
// Entrada esperada
E-mail válido: teste@a2gtest.com e senha correta fornecidos pelo usuário.
// Saída esperada
✓ O usuário é autenticado com sucesso e redirecionado para o dashboard. O token JWT é gerado e armazenado. A sessão é iniciada corretamente e o nome do usuário é exibido na barra de navegação.
